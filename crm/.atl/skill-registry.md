# Skill Registry

## Project Conventions
- Source: `AGENTS.md`
- Workflow: Epic → Module → Task → PR Task → PR Module → PR Final → dev
- Branches: `feat/startup-crm/*` for epic/module, `task/*` for tasks
- Commits: Conventional Commits only
- Persistence: Engram required
